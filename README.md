# Tehachapi Lifestyle

A responsive editorial guide to visiting and exploring life in Tehachapi, California. Built with Vite and vanilla JavaScript, with a cinematic hero video, wine-country feature, visitor itinerary, tailored planning paths for weekend guests and prospective movers, responsive image storytelling, community guide, FAQs, and a local-only visit/move brief.

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Media and design

The supplied Tehachapi Lifestyle logo is used in the header and footer. The hero uses free stock mountain footage hosted by Pexels, with a real frame from the footage as its poster and still-image fallback; it can be paused or played with the motion control. Supporting photos are sourced from local visitor, community, and winery sites, with a Tehachapi mountain landscape layered subtly behind the page. Interface patterns (animated ticker, reveal transitions, choice cards, and FAQ accordions) are custom-built in the spirit of component-led showcases such as 21st.dev.

The site is an editorial planning guide. Community links open official external sources; the move-brief form creates a local copy and does not submit any information.
